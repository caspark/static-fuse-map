Static fuse map, animated

A static fuse map stores each key/value as one XOR equation. Construction peels those equations into an order that can be solved backward; lookup just reads three cells and XORs them. This visualization uses real strings and deterministic 64-bit hashes, but displays 8-bit values so the bit patterns are readable.

1. Hash each key to three cells

key → h0, h1, h2. The real crate uses XXH64 then a seed mix; this page uses the same kind of 64-bit mixing in JavaScript.

2. Solve XOR equations

table[h0] ⊕ table[h1] ⊕ table[h2] = value. Peeling finds a cell that belongs to only one remaining key.

3. Verified mode adds a second equation

check[h0] ⊕ check[h1] ⊕ check[h2] = fingerprint. If this fails on lookup, the key is absent.
